# Поддержка проекта приостановлена

**Статус: поддержка Gallerate временно приостановлена.**

Дата объявления: 21 октября 2026.

## Что это значит на практике

| | |
|---|---|
| Новые функции | Не появятся, пока поддержка не возобновится |
| Исправления ошибок | Не выпускаются |
| Issues | Принимаются, но не обрабатываются — отвечать буду медленно или не отвечу вовсе |
| Pull requests | Принимаются. С ними разберусь, когда вернусь к проекту |
| Актуальная версия | Та, что в репозитории сейчас: `0.3.0+3` |

Приложение при этом **продолжает работать**: код выложен целиком, ничего не
закрыто и не вырезано. Сборка из исходников воспроизводима (см. раздел
«Запуск» в [README](README.md)), все 251 тест проходят.

## Почему

Приостановка не означает, что проект плохой или его больше не нужно. Это
означает, что у автора сейчас другие приоритеты, и он честнее скажет об
этом прямо, чем будет делать вид, что issues вижу, а релизы выходят.

## Как пользоваться

Приложение бесплатное, офлайновое, без аккаунтов, телеметрии и сети — все
оценки хранятся только на устройстве. Сборка из исходников:

```powershell
flutter pub get
flutter build apk --release --split-per-abi
```

## Если хочется продолжить

Форк приветствуется. Всё, что нужно для старта, есть в репозитории:

- `README.md` — возможности, запуск, архитектура, разбор решений;
- `SUPPORT` этого файла — что именно остановлено;
- `lib/` — весь код приложения (29 файлов, Dart, без сгенерированного);
- `test/` — 251 тест, включая виджет-тесты всех экранов;
- `docs` в истории коммитов — решения по ключевым местам.

Код написан так, чтобы его можно было читать и менять: зависимости
внедряются явно, состояние отделено от виджетов, а тесты проверяют
поведение, а не детали вёрстки.

## Когда поддержка вернётся

Прогнозов не даю — они почти всегда оказываются неверными. Как только
работа над проектом возобновится, эта страница будет обновлена, а
объявление в [README](README.md) снято. До тех пор считайте репозиторий
замороженным, но пригодным для форка.
